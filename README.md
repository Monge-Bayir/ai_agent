## О проекте

Система автономных AI-агентов, способных выполнять сложные многошаговые задачи в веб-браузере без постоянного участия пользователя. Каждый агент специализируется на определенной области и использует AI для принятия решений.

### Зачем это нужно?

- 🎯 **Автоматизация рутинных задач** - поиск работы, очистка почты, заказы
- 🤖 **AI-driven решения** - агент сам анализирует и принимает решения
- 🔒 **Безопасность** - подтверждение критичных действий
- 🔄 **Адаптивность** - работает даже при изменении структуры сайтов

### ✅ 4. Продвинутые паттерны

#### ✓ 4.1 Sub-agent Architecture

```python
class AgentCoordinator:
    def __init__(self):
        self.agents = {
            "email": EmailAgent(),           # Эксперт по почте
            "ecommerce": FoodDeliveryAgent(), # Эксперт по заказам
            "job_search": JobSearchAgent()   # Эксперт по работе
        }
    
    def select_agent(self, task: str):
        # Выбирает специализированного агента
        if 'почта' in task: return self.agents["email"]
        if 'еда' in task: return self.agents["ecommerce"]
        if 'работа' in task: return self.agents["job_search"]
```

**Специализации:**

| Агент | Область | Уникальные возможности |
|-------|---------|------------------------|
| **JobSearchAgent** | Поиск работы | • AI scoring вакансий<br>• Генерация писем<br>• Анализ профиля |
| **EmailAgent** | Почта | • Keyword spam detection<br>• Классификация важности<br>• Безопасное удаление |
| **FoodDeliveryAgent** | Заказы | • Нормализация названий<br>• Управление корзиной<br>• Checkout flow |

#### ✓ 4.2 Adaptive Error Handling

```python
class AdaptiveErrorHandler:
    async def handle_error(error, page):
        if "timeout" in error:
            # Элемент не найден → ищем альтернативы
            alternatives = [
                'button[aria-label="Submit"]',
                'button:has-text("Отправить")',
                '[data-qa="submit"]'
            ]
            for selector in alternatives:
                if await page.locator(selector).count() > 0:
                    return selector  # Найдена альтернатива!
        
        elif "navigation" in error:
            # Медленная загрузка → увеличиваем timeout
            await asyncio.sleep(3)
            return retry_action
```

**Стратегии:**
- 🔄 Timeout → 8+ альтернативных селекторов
- 🔄 Navigation → Увеличение времени ожидания
- 🔄 Element detached → Обновление контекста
- 🔄 Unknown → Отладочная информация + скриншот

**Пример работы:**
```
❌ Ошибка: selector timeout для 'button[id="submit-123"]'
🔍 Ищу альтернативы...
   ✓ Найдено: button:has-text("Отправить")
✅ Успешно выполнено через альтернативный селектор
```

#### ✓ 4.3 Security Layer

```python
class SecurityLayer:
    DESTRUCTIVE_KEYWORDS = [
        'delete', 'удалить',   # Удаление
        'pay', 'оплатить',     # Оплата
        'purchase', 'купить'   # Покупка
    ]
    
    def requires_confirmation(action, context):
        return any(kw in action.lower() for kw in DESTRUCTIVE_KEYWORDS)
    
    async def request_confirmation(description):
        print(f"⚠️ ТРЕБУЕТСЯ ПОДТВЕРЖДЕНИЕ: {description}")
        return input("Продолжить? (y/n): ") == 'y'
```

**Защищенные действия:**

| Действие | Триггер | Пример |

| 🗑️ Удаление | `delete`, `удалить` | Удаление писем |

## Технические решения

### 1. Нормализация названий

**Проблема:** "Вкусно и точка" ≠ "Вкусно – и точка"

**Решение:**
```python
def normalize(name):
    name = re.sub(r'[^\w\s]', '', name.lower())
    return ' '.join(name.split())

# "Вкусно и точка" → "вкусно и точка"
# "Вкусно – и точка" → "вкусно и точка"
# Теперь совпадают! ✅
```

### 2. Множественные селекторы

**Проблема:** Сайты меняют структуру

**Решение:** 8+ вариантов для каждого элемента
```python
selectors = [
    "[data-qa='message']",      # Новый
    ".mail-MessageSnippet",     # Старый
    "[role='listitem']",        # Семантический
    "article"                   # Альтернатива
]
```

### 3. JavaScript fallback

**Проблема:** Playwright не находит элементы

**Решение:** JavaScript анализ страницы
```python
elements = await page.evaluate("""
    () => Array.from(document.querySelectorAll('div'))
        .filter(el => el.textContent.includes('@'))
        .map(el => ({text: el.textContent}))
""")
```

class AdaptiveErrorHandler:
    async def handle_error(error_ctx, page, agent):
        # Анализируем тип ошибки
        if "timeout" in error_ctx.error_message.lower():
            # Элемент не найден - ищем альтернативные селекторы
            return await _find_alternative_selectors(error_ctx, page)
        
        elif "navigation" in error_ctx.error_message.lower():
            # Проблемы с загрузкой - увеличиваем timeout
            await asyncio.sleep(3)
            return error_ctx.action_attempted  # Retry
        
        else:
            # Неизвестная ошибка - показываем отладочную информацию
            return await _show_debug_info(error_ctx, page)

#### 4.3 Security Layer

```python
class SecurityLayer:
    DESTRUCTIVE_KEYWORDS = [
        'delete', 'удалить',      # Удаление данных
        'pay', 'оплатить',        # Финансовые операции
        'purchase', 'купить',     # Покупки
        'confirm order'           # Подтверждение заказа
    ]
    
    @staticmethod
    def requires_confirmation(action: str, context: str) -> bool:
        """Проверяет, требуется ли подтверждение пользователя"""
        for keyword in SecurityLayer.DESTRUCTIVE_KEYWORDS:
            if keyword in action.lower() or keyword in context.lower():
                return True
        return False
    
    @staticmethod
    async def request_confirmation(action_description: str) -> bool:
        """Запрашивает подтверждение у пользователя"""
        print(f"⚠️  ТРЕБУЕТСЯ ПОДТВЕРЖДЕНИЕ:")
        print(f"   {action_description}")
        response = input("   Продолжить? (y/n): ")
        return response.strip().lower() == 'y'
```

## Технические решения

### 1. Нормализация названий для поиска

**Проблема**: "Вкусно и точка" vs "Вкусно – и точка" (тире вместо дефиса)

**Решение**:
```python
def normalize_name(name: str) -> str:
    import re
    # Убираем все кроме букв и пробелов
    name = re.sub(r'[^\w\s]', '', name.lower())
    # Убираем лишние пробелы
    name = ' '.join(name.split())
    return name

# "Вкусно и точка" → "вкусно и точка"
# "Вкусно – и точка" → "вкусно и точка"
# Теперь они совпадают!
```

### 2. Множественные стратегии поиска элементов

**Проблема**: Веб-сайты постоянно меняют структуру

**Решение**: 8+ селекторов для каждого типа элементов
```python
email_selectors = [
    "[data-qa='message-item']",      # Современный Яндекс
    ".mail-MessageSnippet",          # Старый Яндекс
    "[role='listitem']",             # Семантический HTML
    "article",                       # Альтернативная разметка
    # ... еще 4 варианта
]

for selector in email_selectors:
    if await page.locator(selector).count() > 0:
        # Нашли! Используем этот селектор
        break
```

### 3. JavaScript поиск как fallback

**Проблема**: Playwright селекторы не находят элементы

**Решение**: JavaScript анализ всей страницы
```python
# Если все селекторы не сработали, ищем через JS
elements = await page.evaluate("""
    () => {
        // Ищем все элементы, похожие на письма
        const allElements = document.querySelectorAll('div, article');
        return Array.from(allElements)
            .filter(el => {
                const text = el.textContent;
                // Признаки письма: email, дата, разумная длина
                return text.includes('@') && 
                       text.length > 30 && 
                       text.length < 1000;
            })
            .map(el => ({ text: el.textContent }));
    }
""")
```
